# Material Art Visual Language

本文件定义一套艺术家中立、来源中立的材料艺术方法。它只描述可执行的材料、空间、色彩和叙事规则，不保存或输出任何来源艺术家的姓名、履历、原作标题、价格、联系方式、展览事实或视觉图册。

## 核心结构

材料艺术不是给图像添加粗糙纹理，而是让现实矛盾通过材料的前史、物性和空间关系被看见。

稳定公式：

`现实矛盾 -> 材料前史 -> 物理动作 -> 空间结构 -> 未解决的问题`

主要张力可以来自：

- 温柔色彩 vs. 粗粝材料
- 平面图像 vs. 突出结构
- 旧物前史 vs. 新技术
- 秩序框架 vs. 叙事断裂
- 透明容器 vs. 不规则核心
- 个体尺度 vs. 城市或机器尺度

## 四种工作模式

| 模式 | 结构特征 | 适合主题 | 常见失败 |
|---|---|---|---|
| `material-topography` | 回收木、砂、石膏、旧板材、网、玻璃被压成浅浮雕地形 | 劳动、土地、迁徙、家庭与城市变化 | 只有表面颗粒，没有主锚点或材料因果 |
| `psychological-interior` | 双联、剖面、洞口、折叠与遮挡形成内部空间 | 梦、欲望、创伤、亲密关系与道德冲突 | 字面符号太多，像插图或舞台布景 |
| `machine-reflection-stage` | 地面、背景板、设备、人物痕迹和观看距离组成微型剧场 | 自动化、劳动替代、陪伴、战争与权力 | 通用科幻、产品展示、无关系的机器人装饰 |
| `translucent-core` | 半透明容器与不规则核心形成观察距离 | 脆弱、封存、时间、生命短暂与技术变化 | 商业摆件、悬浮无支撑、光滑渐变塑料感 |

每次选择一个主模式。最多允许另一模式提供局部材料或空间支持，不把四种模式平均混合。

## 材料语义库

| 材料 | 物性 | 可承载的现实记忆 | 适合动作 |
|---|---|---|---|
| 回收木/旧家具木 | 划痕、孔洞、纹理、结构强度 | 家庭、居住、劳动、修补、迁徙 | 切割、拼接、架起、开窗、外露、铰接 |
| 砂/石膏/碎石/砖粉 | 粗糙、沉积、易崩裂、有重量 | 土地、磨损、建设、废墟、时间 | 堆积、涂抹、剥开、压入、露底 |
| 工业网/纤维网 | 透视、遮挡、柔软、临时性 | 建设、保护、控制、污染、迁移 | 拉伸、包裹、遮蔽、悬吊、穿透 |
| 树脂/亚克力/再铸玻璃 | 透明、封存、折射、工业精度 | 科技、观察、脆弱、保存、幻象 | 浇铸、封装、夹持、透光、嵌入 |
| 金属线/机械部件 | 冷硬、骨架化、连接与控制 | 自动化、生产、战争、被操控的身体 | 弯折、悬置、连接、断开、暴露结构 |
| 日常现成物 | 保留使用痕迹和社会位置 | 身体劳动、家庭角色、阶层、地方经验 | 错置、放大、切开、嵌入、与新材料冲突 |
| 油彩/丙烯/染料 | 覆盖、渗透、色场、表皮 | 情绪温度、修复、遮蔽、视觉诱惑 | 覆盖、擦除、渗入、分区、保留底层 |

每件作品使用 3-5 种主材料。至少一种材料应与主题的真实生活现场有关；无法确认来源时，明确写成概念假设，不把推测当事实。

## 材料动作词库

- **拼接：** 保留不同材料之间的断面与冲突。
- **穿插：** 让一个时间层或权力关系进入另一个结构。
- **交叠：** 允许记忆或图像互相遮挡，不把信息全部展开。
- **并置：** 让差异在同一观看面上保持张力。
- **嵌入：** 强调封存、依附或无法分离。
- **悬吊：** 强调脆弱、等待或重力风险。
- **剥开：** 暴露被覆盖的前史，不做随机破损。
- **压住：** 表达控制、负担或地层关系。

每种动作必须同时有叙事职责和结构理由。

## 构图原型

### 1. 不闭合脚手架 + 内部地形

一个木或金属边界承担观看秩序，内部是压缩材料、色场和少量突出物。主锚点偏离中心，至少一个结构跨出平面。

### 2. 不对称双联 + 缺失连接

两块体量或色温不相等的面板共享一种材料，但使用相反动作。中间保留一道不被填满的缝。

### 3. 透明容器 + 不规则核心

容器几何、核心非几何。透明面负责距离与观察，核心负责时间与脆弱。光源必须解释折射、投影和厚度。

### 4. 微型剧场 + 权力距离

地面、背景板、设备或主体痕迹构成舞台。通过站立、低头、缺席、拆散、被观看或被控制表现关系。

### 5. 剖面边界 + 被遮住的内部

边界同时像墙、柜子、门或身体剖面。只展示局部内部；至少一个区域保持被覆盖状态。

## 表面与结构分工

| 区域 | 表面策略 | 目的 |
|---|---|---|
| 主色场 | 低频、较平滑、微弱刷痕 | 给结构与材料留下阅读空间 |
| 时间/劳动区 | 砂、石膏、磨痕、裸木、旧孔洞 | 让材料前史可见 |
| 边界结构 | 木、金属、硬边、清楚连接 | 建立秩序和观看路径 |
| 叙事线索 | 1-3 种小型异质材料 | 提供非线性跳转 |
| 静区 | 低对比、少纹理、无装饰 | 让观众停顿 |

## Transform 档位与人物抽象阈值

### `scene-preserving`

- 用于用户明确要求保留身份、肖像、服装、建筑细节或纪实场景。
- **单个人物：** 可中度抽象，但整体轮廓、自然解剖、姿态、视线和 1-2 个身份特征要可辨认。
- **两个及以上人物：** 保留准确人数、完整身体、相互距离、尺度、朝向和互动关系；压缩面部与服装细节，不删除人来制造留白。
- 中间调压缩为 2-4 个材料层，不能只在照片上增加颗粒、石膏纹理或浮雕阴影。

### `semantic-abstract`

- 普通“照片转材料艺术 / 材料蒙太奇”默认使用；用户说“太像原图”“更抽象”“不要写实”“只保留动作或关系”时必须使用。
- **单个人物：** 压缩成一个连续材料身体向量，用折叠、倾斜、拉力、支撑和 1-2 个色彩或物件锚点保存原始动作；不复制面孔、皮肤、服装褶皱或摄影轮廓。
- **两个及以上人物：** 每个人对应一个可区分、完整的材料身体向量。准确保留人数、相互距离、尺度、朝向和互动关系，但允许用织物柱、折板、矿物块或橡胶模块替代写实解剖；不能变成无差别的点、钉子或纹理。
- **动物：** 用一个完整材料体量和 1-2 个物种锚点保留数量、方向、尺度与群体关系；不做标本或写实毛发复制。
- **地标与山体：** 压缩为 2-4 个大材料板、中央轴线和 2-3 个身份特征，再通过错位、叠压、缺口、梁和支撑重组。身份仍可回认，但不得保留摄影透视和逐层描摹。
- **群体中的静区：** 通过简化地面、天空、建筑和次要物件获得，不通过删除主体或改变数量获得。

### 动作到材料的编码

| 源图动作 | 材料转译 |
|---|---|
| 合掌 / 手举过头 | 两块相接的折板、铜片或织物三角，接缝承担动作 |
| 行走 / 跛行 / 借力 | 倾斜身体向量、金属杆、受压触点与断开的路径线 |
| 背负 / 携带 | 两个相互受力的织物体、吊带、包裹与重心偏移 |
| 并坐 / 并立 | 多个独立材料体共享一根梁或地面，但连接故意不闭合 |
| 远眺地标 | 小型材料体朝向一组大轮廓板，尺度差承担观看关系 |

### 失败判定

- 缩到 10% 时先像照片、写实油画或浅浮雕滤镜，材料只是一层表面效果。
- 人脸、皮肤、服装和山石仍被逐边描摹，只是统一换成石膏或颗粒。
- 为了“抽象”而删除人物、改变数量、打乱朝向，或把群体统一做成圆点和钉子。
- 抽象形式与源图动作无关，无法解释某块材料为何必须这样折、压、绑或断开。

## 原创与隐私门

- 不保存或输出来源艺术家的姓名、履历、联系方式、作品价格、展览事实或视觉图册。
- 不沿用参考作品的标题、署名、展签、人物姿态、完整物件组合或展陈关系。
- 不把文化符号、机器人、粉彩、透明树脂或废料当成自动风格标签。
- 用户要求直接复刻时，至少改变主题、材料前史、构图和观看关系中的三个维度。
- 最终生成 Prompt 只描述材料、物性、空间动作、色彩和叙事，不写来源身份。
