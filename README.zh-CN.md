# ZONE-Material-art

这是一个艺术家中立的个人 Codex Skill。它从现实矛盾出发，为材料建立前史，再用拼接、穿插、交叠、并置和主动框架形成原创绘画或装置。

## 能做什么

- 把一个社会、个人、文学或科技主题转成原创混合媒介作品方案
- 把照片转译成材料地形、浅浮雕绘画或空间装置，并区分场景保真与语义抽象
- 输出可复制的图片生成 Prompt，并在要求时直接生成/编辑图片
- 设计实体材料、连接节点、尺寸、运输与现场安装计划
- 审查作品为什么像随机拼贴、通用粉彩、商业 3D、东方符号堆砌或赛博朋克机器人
- 规划一组作品的展陈关系与观众动线

## 如何调用

在新任务中直接说：

```text
使用 $zone-material-art，把“被算法改写的家庭相册”做成一件原创材料艺术作品。
```

也可以说：

```text
用 ZONE-Material-art 审查这张图，只给修改意见，不要重画。
```

```text
把这张照片转成材料地形，保留人物和原图比例，直接生成。
```

```text
把这张照片做成材料艺术，不要像照片浮雕，只保留人物数量、动作、关系和关键色彩。
```

```text
做一件关于 AI 陪伴的机器镜像剧场，最后给我实体制作清单。
```

## 四种模式

- `material-topography`：材料地形，适合劳动、土地、迁徙、村落与现代化断裂
- `psychological-interior`：心理内部，适合梦、欲望、创伤和心理冲突
- `machine-reflection-stage`：机器反思剧场，适合人机关系、劳动、战争与陪伴
- `translucent-core`：透明核心，适合脆弱、封存、短暂、技术变化与重生

每次只选一个主模式。核心不是模仿某位艺术家的表面风格，而是让主题、材料、空间和观看关系真正互相解释。

## 照片转译的两个档位

- `scene-preserving`：用户明确要求保留身份、肖像、服装、建筑细节或纪实场景时使用。结果仍需压缩摄影中间调，不能只加材料纹理。
- `semantic-abstract`：普通材料艺术转译的默认档位。只保留主体数量、位置、方向、动作、互动关系与 1-2 个身份锚点，把人物、动物和地貌重组为材料身体向量与大材料板。

如果用户反馈“太像原图”“不适合”“更抽象”“不要写实”，Skill 会直接切到 `semantic-abstract`。质量门要求缩到 10% 时先读成材料装配，再从数量与动作回认源图；照片浮雕化、写实面孔和服装描摹都视为失败。

## 隐私与原创边界

Skill 只保存材料履历、空间结构、叙事方法、色彩分支和质量门，不保存或输出任何来源艺术家的姓名、履历、原作标题、价格、联系方式、展览事实或参考图册。它不生成艺术家署名、伪展签、伪价格，也不把参考作品的识别性构图直接套到新作品上。

安装后请开启一个新任务，让 Codex 重新发现 Skill。
